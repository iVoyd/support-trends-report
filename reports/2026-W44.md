## Recommendations

### Documentation and content corrections

- **Docs fix: Correct the secure_password_change description in the CLI config reference**  
  The CLI config reference describes auth.email.secure_password_change as requiring the current password, but it actually maps to reauthentication, and no config.toml key exists for the real setting. Update the description to say it controls reauthentication and document the correct key or remove the misleading entry.  
  Based on: [#52547](https://github.com/supabase/supabase/issues/52547), [#52546](https://github.com/supabase/supabase/issues/52546)
- **Docs fix: Fix SMTP port type in the curl example and add the Management API contract**  
  The SMTP setup example sends smtp_port as a number, but the API rejects it with 'expected string, received number', so the example should send the port as a string. Also clarify the migration endpoint's transaction, history atomicity and request-size contract in the Management API docs.  
  Based on: [#52384](https://github.com/supabase/supabase/issues/52384), [#52304](https://github.com/supabase/supabase/issues/52304)
