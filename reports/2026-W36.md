## Recommendations

### Dashboard account access, MFA and billing

- **Bug triage priority: Prioritise the auth.supabase.io 301 redirect loop affecting dashboard sign-in**  
  Many reports describe ERR_TOO_MANY_REDIRECTS and 'Failed to fetch (auth.supabase.io)' on the dashboard sign-in, with a CORS preflight returning HTTP 301 to itself, starting around 1 Sep 2026. Treat this as one incident and link duplicates to a single tracking issue, since it blocks users from reaching support tickets.  
  Based on: [#49847](https://github.com/supabase/supabase/issues/49847), [#49816](https://github.com/supabase/supabase/issues/49816), [#49822](https://github.com/supabase/supabase/issues/49822), [#49827](https://github.com/supabase/supabase/issues/49827), [#49812](https://github.com/supabase/supabase/issues/49812)
- **FAQ entry: Dashboard login fails with redirects or 'Failed to fetch' on auth.supabase.io**  
  Support should tell users this is a sign-in service problem, not an error in their project, and to check status.supabase.com and retry later in a fresh browser session. Users locked out of the dashboard should contact support through a channel that does not require dashboard login, such as email from the account's registered address.  
  Based on: [#49819](https://github.com/supabase/supabase/issues/49819), [#49814](https://github.com/supabase/supabase/issues/49814), [#49827](https://github.com/supabase/supabase/issues/49827), [#49910](https://github.com/supabase/supabase/issues/49910)

### SQL Editor and Table Editor

- **Bug triage priority: Prioritise identifier-escaping bug in row export (formatTableRowsToSQL)**  
  Three duplicate issues report that Copy as SQL and Export as SQL do not escape embedded double quotes in schema, table, or column names, producing invalid SQL for valid identifiers such as customer"name. Triage the fix as one item, since the duplicates share a single root cause in formatTableRowsToSQL.  
  Based on: [#49977](https://github.com/supabase/supabase/issues/49977), [#49979](https://github.com/supabase/supabase/issues/49979), [#49978](https://github.com/supabase/supabase/issues/49978)
- **Bug triage priority: Fix Table Editor row count when filtering by zero**  
  The Table Editor grid filters rows correctly for a numeric filter of 0 but the row count still shows the full table count, which is misleading when users inspect filtered data. Schedule this alongside the other Table Editor filtering fixes this week.  
  Based on: [#49776](https://github.com/supabase/supabase/issues/49776)
